Topics

Topics are generated for this module and stored per user. You can edit names, add your own topics, or remove any topic before generating quizzes.

Notes (PDF Upload → Quiz Context)

Upload lecture notes or your own PDFs. The app extracts text snippets in the browser and uses them to generate better personalized quiz questions. When you are logged in, the PDF file and extracted snippet are uploaded to the backend and stored using Django file storage (local media by default, cloud-storage-ready if configured).
